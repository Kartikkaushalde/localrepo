# E-Commerce Sales & Customer Analytics

A portfolio-ready Data Analyst project using Python, Pandas and SQL to analyze e-commerce sales performance, customers, products and profitability.

## Business Questions
- Which product categories generate the most revenue?
- Which regions and customer segments perform best?
- How do discounts affect profit?
- What are the monthly sales trends?
- Which products and customers contribute most to revenue?

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Data analysis and KPI reporting

## KPIs
- Total Revenue
- Total Orders
- Units Sold
- Average Order Value
- Total Profit
- Profit Margin
- Repeat Customer Rate
